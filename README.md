# 🤖 ROBEX – Smart Autonomous Robot Server

ROBEX is a **unified intelligent robot control system** that integrates  
AI, Computer Vision, Voice Interaction, IoT, and Web Technologies  
into **one single server**.

This project was developed as a **final-year engineering project** and is suitable for:
- Project demonstration
- Research paper (IEEE)
- College exhibitions
- Real-world robotic interaction systems

## 🧠 Core Capabilities

- 🤖 AI-based command understanding (Google Gemini)
- 📷 ESP32-CAM live video streaming
- 🎓 Face Recognition Attendance System
- 🕹 Manual robot movement control
- 🎤 Voice command processing
- 🔊 Neural Text-to-Speech (Male/Female, Multilingual)
- 🦾 Servo motor (neck/head rotation) control
- 🌐 Web-based futuristic dashboard UI
- 🔁 Single unified Flask server (no multiple scripts)
